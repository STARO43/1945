ИНСТРУКЦИЯ: публикация сайта на GitHub Pages
=============================================

Это ГОТОВАЯ сборка сайта «1941–1945. Великая Отечественная война».
Здесь только файлы сайта (без исходников) — GitHub Pages отдаёт их как есть.

ВАЖНО: сайт должен стоять в «корне», поэтому репозиторий должен называться
  ваш-логин.github.io
(где ваш-логин — ваше имя пользователя на GitHub). Тогда сайт откроется по
адресу https://ваш-логин.github.io

ШАГИ (GitHub Desktop + браузер):

1. На github.com в браузере: нажмите «+» справа вверху → New repository.
   Имя репозитория: ваш-логин.github.io (замените ваш-логин на свой логин).
   Public, без галочек README → Create repository.

2. В GitHub Desktop: File → Clone Repository → выберите этот репозиторий
   → укажите локальную папку → Clone.

3. Откройте локальную папку репозитория. УДАЛИТЕ из неё файл ИНСТРУКЦИЯ.txt
   (он нужен только вам) и скопируйте туда ВСЁ остальное содержимое этой
   папки github-pages-site (файл index.html, папки _next, media, fonts,
   robots.txt, 404.html и остальные файлы) — прямо в корень репозитория.

4. В GitHub Desktop: слева вверху появится список изменений.
   Внизу напишите что-нибудь (например «Сайт») → нажмите
   «Commit to main» → затем кнопку «Push origin».

5. Подождите 1–2 минуты. В браузере откройте:
   https://ваш-логин.github.io
   Сайт должен открыться.

Если страница ещё не появилась — зайдите в Settings репозитория → слева
«Pages» → убедитесь, что Source = «Deploy from a branch», Branch = main,
папка / (root) → Save.

Файл ИНСТРУКЦИЯ.txt можно удалить из репозитория в любой момент — на сайт
он не влияет.
