# 1941—1945 / История Великой Отечественной

Вторая версия. Две страницы: режиссированная хроника и архив с просмотром подлинных фотографий.

## Посмотреть

Готовая сборка находится в `dist/`. Для Taxi.js и загрузки текстур нужен HTTP-сервер: двойной клик по HTML через `file://` не является поддерживаемым способом запуска.

Если установлен Node.js, запустите `start-preview.cmd` или выполните `node preview.mjs`. Откройте `http://127.0.0.1:8767/`. Дополнительные npm-пакеты для просмотра сборки не нужны.

Для публикации загрузите содержимое `dist/` на Netlify или другой статический хостинг. Внешние подключения не нужны: изображения, шрифты и библиотеки входят в сборку. Ссылки на источники открывают внешние сайты только по нажатию.

## Исходный код

- `src/app.js`: жизненный цикл, Taxi.js, Lenis, GSAP, SplitText, Flip, InertiaPlugin, доступность.
- `src/fluid.js`: GPU-симуляция жидкости и финальный композит.
- `src/style.css`: визуальный дизайн, мобильная версия, reduced motion.
- `index.html`: хроника.
- `archive.html`: архив и исходный предоставленный текст.
- `src/media.json`: данные о фотографиях.
- `src/content.js`: ваши газетные сканы, видео и подписи.
- `public/media/`: локальные фотографии; сюда можно добавить свои файлы.
- `public/fonts/`, `public/fonts.css`: локальные шрифты.

## Разработка

```text
npm install
npm run dev
npm run build
```

`npm run dev` открывает сервер на http://127.0.0.1:8766/. `npm run build` пересобирает обе страницы в `dist/`. Зафиксированные версии и package-lock.json входят в проект. Если основной реестр недоступен, можно настроить доступный npm registry; код приложения от CDN не зависит.

## Как устроены эффекты

Стек соответствует изученному main.js: Three.js r184, GSAP 3.13.0 с ScrollTrigger/SplitText/Flip/InertiaPlugin, Lenis 1.2.3, Taxi.js и Vite. Это новая читаемая реализация тех же механизмов, а не копия чужой минифицированной сборки.

Жидкая маска: ping-pong render targets скорости, давления и красителя; curl/vorticity; advection; divergence; 20 итераций Якоби; вычитание градиента; композит фотографии. Десктоп: симуляция 256², краситель 512². Мобильная версия: 128²/256² и 12 итераций. Pixel ratio ограничен. Симуляция останавливается вне экрана и при скрытой вкладке.

ScrollTrigger режиссирует раскрытие кадра Москвы, параллакс и горизонтальную хронологию. SplitText использует реальные строки и символы. Flip переносит сам элемент фотографии в полноэкранный просмотр и возвращает его. InertiaPlugin отвечает за интерактивную редакционную печать. Скоростной глитч привязан к прокрутке. Taxi удаляет старые триггеры, обработчики, текстовые разбиения и WebGL-ресурсы при переходе.

Учитывается prefers-reduced-motion. Круглая кнопка ≈ позволяет переключить анимацию. При отключении остаются весь рассказ и фотографии, нет пиннинга и симуляции. При отсутствии нужных WebGL-возможностей показывается обычная архивная фотография. Меню поддерживает Escape, управление фокусом и Tab; фото открываются кнопками и закрываются Escape.

## Архивные материалы

Три экранные копии AWM скачаны локально. В карточках источника указано Copyright expired / public domain:

- Москва, около июня 1941: AWM 008817, неизвестный британский официальный фотограф. https://www.awm.gov.au/collection/C30144
- Сталинград, октябрь 1942: AWM P02018.133, фотограф в карточке не указан. https://www.awm.gov.au/collection/C307157
- Берлин, 1945: AWM P04054.006, фотограф неизвестен. https://www.awm.gov.au/collection/C1018250

Фотографии кадрируются и показаны в монохромной/тонированной обработке. Для большой экспозиции их можно заменить более качественными копиями. Не выдавайте июньский московский снимок за фотографию декабрьского контрнаступления: разграничение дат уже подписано в интерфейсе.

Газетные вырезки и видеохроника не выдуманы и не заменены стоками. Добавьте свои файлы через массив `documents` в `src/content.js`; примеры полей приведены там. До добавления файла видеоплеер не отображается. Видео имеет стандартные органы управления и останавливается вне экрана.

Предоставленный пользователем текст сохранён без изменений в archive.html, с оговоркой об неизвестных авторе/издании, идеологических оценках и необходимости исторического комментария. Основной рассказ не повторяет утверждения о национальном превосходстве и спорные героические эпизоды как проверенные факты. Опорные исторические источники приведены на странице.
