# 1941–1945. Великая Отечественная война

Одностраничный сайт-история в лёгкой современной визуальной стилистике: плавные скролл-анимации, «вылетающие» листы для чтения, видеофоны, кастомный курсор и прелоадер. Хроника войны от нападения на СССР до разгрома Японии.

## Стек

- **Next.js 16** (App Router, статический рендеринг)
- **React 19**
- **Tailwind CSS 4**
- **Framer Motion** — все анимации и переходы

Требуется **Node.js 20.9+**.

## Быстрый старт

```bash
# 1. Установить зависимости (любой из вариантов)
npm install
# или
bun install

# 2. Запустить дев-сервер
npm run dev
# или
bun run dev
```

Открыть http://localhost:3000

```bash
# Продакшен-сборка и запуск
npm run build
npm run start
```

## Структура проекта

```
src/
├── app/
│   ├── layout.tsx        # метаданные страницы (title, description)
│   ├── page.tsx          # сборка страницы из секций
│   ├── globals.css       # темы, зерно, базовые стили
│   └── fonts.css         # подключение локальных шрифтов
├── components/site/      # все компоненты сайта
│   ├── Preloader.tsx     # прелоадер
│   ├── Cursor.tsx        # кастомный курсор
│   ├── Hero.tsx          # первый экран с видео-фоном
│   ├── Overview.tsx      # обзор частей
│   ├── Header.tsx        # шапка
│   ├── Marquee.tsx       # бегущая строка
│   ├── PartSection.tsx   # секции Часть I–VIII
│   ├── Sheet.tsx         # «вылетающие листы» для текста
│   ├── SwarmScene.tsx    # сцена частиц
│   ├── Timeline.tsx      # таймлайн
│   ├── ChevronFrame.tsx, ChevronWordmark.tsx, Footer.tsx
│   └── ...
└── lib/
    ├── data.ts           # ВЕСЬ контент: тексты, даты, фото, видео
    └── utils.ts
public/
├── media/photos/         # 20+ исторических фотографий
├── media/videos/         # 5 документальных видео (mp4)
├── media/manifest.json   # источники и лицензии всех медиа
└── fonts/                # локальные шрифты (Inter Tight, JetBrains Mono)
```

## Как вставить свой текст

Весь контент собран в одном файле — **`src/lib/data.ts`**: названия и описания частей, карточки с текстом для «вылетающих листов», подписи к фото и видео. Отредактируйте нужные поля — структура страницы и анимации подхватят их автоматически.

## Медиа

Фотографии и видео — из публичных источников (Wikimedia Commons и др.), лицензии указаны в `public/media/manifest.json`.
